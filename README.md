# axiom-gray-site

Static marketing website for Axiom Gray.  
The project uses Tailwind CSS via CDN and handcrafted HTML with a dark‑themed glass aesthetic.

## Structure

- `index.html` – landing page with hero and quick links to sections
- `approach/` – detailed description of the company philosophy and capabilities
- `services/` – full list of core services offered
- `work/` – case study index
  - `work/case-study-denied-party.html` and `work/case-study-collections.html` for individual projects
- `contact/` – inquiry form and contact details

This hierarchy makes it easy to add nested pages and scale the site over time.
