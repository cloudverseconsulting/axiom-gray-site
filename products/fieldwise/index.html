What it gives admins

The right answer, before a release becomes a fire drill.

Fieldwise is deliberately focused. It gives you a clear working surface for the access questions that otherwise turn into long, repetitive Setup sessions.

01

One field, every access record

Review Read and Edit for the selected field across Profiles and Permission Sets from one table.

02

Multi-field editing

Select a group of fields once, make a precise change, and reuse a reviewed pattern across the selected set.

03

Saved audit records

Capture an object, Profile, or Permission Set as one reusable saved record in Snapshots.

04

Source-to-target comparison

Compare saved records across orgs and start with meaningful differences, not a wall of matches.

05

Controlled deployment

Stage FLS edits locally, review the exact entries, then apply them through Salesforce Metadata API.

06

Local audit trail

Keep local history of applied changes, plus CSV, XLSX, JSON, and XML exports where applicable.

A simple workflow

From question to answer in four deliberate steps.

There is no new process to learn. Fieldwise follows the way Salesforce admins already think about access.

1Pick the work

Use FLS for a field task, or Audit for a record you will revisit or compare.

2Capture context

Save an object audit or a Profile / Permission Set capture in the extension.

3Compare records

Select Source and Target. Differences are surfaced first, with matches still available.

4Apply with review

Stage FLS changes, confirm them, and keep the result in local History.

Release confidence

Compare saved org states, not screenshots and memory.

Capture the same object, Profile, or Permission Set in Dev, QA, UAT, or Production. Then compare the saved Source and Target records inside Fieldwise.

  • Object FLS: fields, Profiles, and Permission Sets
  • Profile / Permission Set: field, object, system, and custom permissions
  • Large captures are stored locally in manageable chunks

Built for real work

Privacy by design

Browser to org. Nothing in between.

Fieldwise uses the active Salesforce session to make direct requests to the connected org. Saved audits, snapshots, history, and settings remain in Chrome extension local storage. Axiom Gray does not receive your Salesforce metadata or credentials.
