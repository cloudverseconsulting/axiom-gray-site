Visual Salesforce architecture maps, directly inside your org.

Four Things. Done Instantly.

01

Instant Relationship Graph

Pick any Salesforce object. Blueprint queries the Metadata API and renders a full relationship network — Lookup, Master-Detail, and Child relationships — in seconds. No Setup navigation required.

02

Relationship Type Filters

Filter by Lookup, Master-Detail, or Child/Dependent relationships. Toggle between Standard, Custom, or both. Zoom in on the connections that matter for the work at hand.

03

Save Views & Export

Save graph configurations locally for objects you return to often. Download the relationship map directly. Share architecture context with your team without rebuilding it from scratch.

04

Privacy First

Blueprint runs in Chrome's side panel using your active Salesforce session. Read-only access only. No data leaves your org. Nothing is sent to Axiom Gray or any third party.

Get Started in 30 Seconds

1

Install Blueprint

Add Blueprint to Chrome from the Chrome Web Store. Free. No account needed.

2

Open Your Salesforce Org

Navigate to any Salesforce org. Open Blueprint from the Chrome side panel — it connects to your active session automatically.

3

Search for Any Object

Type an object name. Blueprint queries the Salesforce Metadata API and returns its full relationship network in seconds.

4

Explore, Filter, Save

Pan and zoom the relationship graph. Filter by relationship type or object scope. Save your view locally or export the map.

Privacy Policy

Your data stays in your browser.

Blueprint is built local-first. There is no backend server. Here is exactly how it works:

What we collect: Nothing.

Blueprint does not collect, store, or transmit any data to Axiom Gray or any third party. No analytics. No tracking. No account required.

How it works

Blueprint uses your active Salesforce browser session to make read-only Salesforce Metadata API requests directly from your browser to your org. Axiom Gray has no servers in this data path.

Local storage only

Blueprint saves recent objects, saved graph views, theme preference, and filter settings to Chrome local storage on your device. This data is never uploaded anywhere.

Read-only access

Blueprint does not modify Salesforce records, metadata, or configuration. It only reads object relationship structure.
