Blueprint  /  Privacy Policy

Privacy Policy

Effective Date: June 14, 2026

Overview

Blueprint is a Chrome extension by Axiom Gray that helps Salesforce users visually explore object relationships and understand Salesforce org architecture.

Blueprint is designed to be privacy-first and local-first. Blueprint does not operate a backend server. Blueprint does not upload Salesforce metadata, saved views, usage history, session cookies, or extension data to Axiom Gray or any third party.

Blueprint runs locally in the user's browser and uses the active Salesforce browser session to make read-only Salesforce metadata API requests.

Data Blueprint Accesses

Blueprint may access the following data only as needed to provide its core functionality:

Salesforce Metadata

Blueprint reads Salesforce metadata from the active Salesforce org, including:

  • —Object API names and labels
  • —Field counts
  • —Lookup relationships
  • —Master-detail relationships
  • —Child relationships

This metadata is used solely to render architecture diagrams and relationship maps.

Authentication Information

Blueprint uses the active Salesforce browser session cookie to authenticate read-only Salesforce metadata API requests. Blueprint does not collect Salesforce usernames, passwords, security tokens, or login credentials. Blueprint does not transmit Salesforce session cookies to Axiom Gray or any third party.

Extension Data Stored Locally

Blueprint may store the following locally in Chrome storage:

  • —Recent objects and recent searches
  • —Saved graph views
  • —Selected theme, filter preferences, and export preferences
  • —Last opened graph

This data remains on the user's device and is never uploaded to Axiom Gray.

Data Blueprint Does Not Collect

Blueprint does not collect:

  • —Salesforce passwords or security tokens
  • —Salesforce records or customer data stored in Salesforce
  • —Full browsing history
  • —Health, financial, or location data
  • —Analytics data or advertising identifiers

Blueprint does not track users across websites.

Read-Only Salesforce Access

Blueprint is a read-only extension. Blueprint does not:

  • —Modify Salesforce records or metadata
  • —Deploy metadata, execute Apex, or run SOQL against business records
  • —Change permissions or configuration
  • —Send data to external services

Chrome Permissions

Blueprint requests Chrome permissions only to provide its core functionality:

tabs

Used to identify the active Salesforce tab and connect the side panel to the correct Salesforce org.

cookies

Used to access the active Salesforce session cookie for read-only Salesforce metadata API authentication.

sidePanel

Used to display Blueprint inside Chrome's side panel alongside Salesforce.

storage

Used to save local preferences, recent objects, saved views, themes, filters, and graph state.

Salesforce Host Permissions

Used so Blueprint can run inside Salesforce domains and read Salesforce metadata from the active authenticated org.

Data Sharing

Blueprint does not sell user data. Blueprint does not share user data with advertisers, analytics providers, data brokers, or third parties. Blueprint does not use external analytics or tracking scripts.

Remote Code

Blueprint does not use remote code. All extension code is packaged with the Chrome extension. Blueprint does not load JavaScript or WebAssembly from external servers.

Data Security

Blueprint avoids collecting unnecessary data and does not transmit Salesforce metadata or session data to Axiom Gray. Because Blueprint stores preferences and saved graph views locally, users should protect access to their browser profile and device.

Children's Privacy

Blueprint is intended for professional Salesforce users and is not directed to children.

Changes to This Policy

Axiom Gray may update this Privacy Policy from time to time. If the policy changes, the updated version will be published at axiomgray.com/products/blueprint/privacy.

Contact

For privacy questions or support, contact Axiom Gray at support@axiomgray.com.
