Getting Started · 01

What is Filer App?

Filer App is a Chrome extension that intercepts your file downloads and automatically renames and sorts them — so your Downloads folder stays organised without any effort.

Every time you download a file, Filer applies your custom rules to decide:

  • What the file should be renamed to
  • Which sub-folder inside Downloads it should go to
  • How the date should be formatted in the filename

You can also install pre-built Persona Packs — curated sets of rules for common workflows like Student, Developer, Finance, and more.

⚡

Works instantly

No configuration required to get started. Download a file and Filer organises it automatically.

🔒

Your files never leave your device. All processing happens locally in your browser.

🎨

Create rules matched to your workflow. Name by source site, file type, date, and more.

Getting Started · 02

Installation

Filer App is available on the Chrome Web Store and takes less than a minute to install.

1

Open the Chrome Web Store

Go to the Filer App listing on the Chrome Web Store. Click Add to Chrome, then confirm by clicking Add extension in the popup.

2

Pin the extension

Click the puzzle icon (🧩) in your Chrome toolbar, find Filer App, and click the pin icon. This keeps the Filer icon visible in your toolbar for quick access.

3

Complete onboarding

Click the Filer icon to open the popup. The first-time setup takes about 60 seconds and helps you choose a persona pack and theme.

4

Grant download permissions

Filer needs permission to manage downloads. You'll be prompted during onboarding — click Allow access. This is required for file renaming to work.

✅ Confirm it's working: Download any file. The Filer popup will show a log entry with the renamed file and source URL. If you see "Ready to organise" instead, try re-granting permissions in chrome://extensions.
Getting Started · 03

Quick Start

The fastest way to get value from Filer is to install a Persona Pack. Your first rule can be live in under two minutes.

Option A — Install a Persona Pack (Recommended)

Persona Packs are pre-built rule sets for common workflows. Open the extension popup → Options → Packs tab, and click Install on any free pack.

Option B — Create your first custom rule

Go to Options → Rules → Add Rule. Fill in:

  • Rule Name — anything descriptive, e.g. "Stripe Invoices"
  • Source domain — e.g. stripe.com
  • Rename pattern — e.g. stripe-invoice-{date}
  • Folder — e.g. Finance/Invoices (relative to Downloads)

Click Save. The rule activates immediately — your next download from Stripe will be renamed and sorted automatically.

ℹ️ Free accounts support up to 3 custom rules and 6 active packs. Upgrade to Pro for unlimited rules and packs.

Core Features · 01

Naming Rules

Rules are the heart of Filer. Each rule tells Filer what to do when a file is downloaded from a specific source.

Rule anatomy

Rule · Stripe Invoices
NAME Stripe Invoices
TRIGGER Source domain contains stripe.com
PATTERN stripe-invoice-{date}
FOLDER Finance/Invoices
RESULT stripe-invoice-2025-06-20.pdf → Downloads/Finance/Invoices/

Rule triggers

Rules activate when the download URL matches your trigger. You can match by:

Trigger typeExampleMatches
Source domainstripe.comAny download from stripe.com or its subdomains
URL contains/invoices/Any URL with this path segment
File extension.pdfAny PDF downloaded from anywhere
Filename containsinvoiceFiles whose original name includes this string
Tab title containsFigmaDownloads while a Figma tab is active

Rule priority

When multiple rules match a download, Filer applies the highest-priority rule (listed first in your Rules tab). Drag rules to reorder them. Rules with more specific triggers should go above generic catch-alls.

⚠️ Free users can create up to 3 custom rules. Rules from installed Persona Packs do not count toward this limit.

Core Features · 03

Template Library

The Template Library lets you browse and apply individual rule templates without installing a full pack.

Navigate to Options → Templates. Free templates are shown immediately at the top. Click any template to preview its pattern, then click Use this template to add it as a custom rule.

You can customise any template after importing — change the rename pattern, trigger domain, or target folder to fit your exact setup.

Core Features · 04

Activity Log

The Activity Log shows a history of every file Filer has processed, including the original name, renamed result, source, and which rule triggered.

Viewing activity

The Filer popup shows your last 5 downloads at a glance. For the full log, go to Options → Activity.

The full log shows:

  • Renamed to — the final filename, and when it was downloaded
  • Folder — the sub-folder inside Downloads where it was saved
  • Source — the domain the file came from
  • Rule — which rule (or pack rule) matched

Export CSV Pro

Pro users can export their full activity history as a CSV file. Free users see the export button as an upgrade prompt.

Retention

Free users retain 30 days of local history. Pro users retain full history with no expiry. History is stored locally and never sent to any server.

Language

Filer's interface is available in 30 languages. Your language is selected during onboarding and can be changed at any time.

Reference · 01

Chrome Permissions

Filer requests the minimum permissions required to function. Here's what each permission is used for.

downloads
Intercept and rename files at the moment of download. Without this, Filer cannot function.
tabs
Read the title and URL of the active tab to help identify the source of a download for smarter rule matching.
storage
Store your rules, settings, and activity log locally in Chrome. No data leaves your device.
<all_urls>
Match download events against rules regardless of which website triggered the download.
🔒 Filer does not read page content, track your browsing history, or transmit data to external servers during normal operation. See the Privacy Policy for full details.

Filename Variables

Use these placeholders in your rename patterns. Filer replaces them automatically at download time.

VariableReplaced withExample
{date}Today's date (your configured format)2025-06-20
{year}Current year (4 digits)2025
{month}Current month (2 digits)06
{day}Current day (2 digits)20
{time}Current time as HHMM1430
{original}Original filename (without extension)invoice_1234
{ext}File extensionpdf
{domain}Source domain, sanitisedstripe-com

Example patterns

stripe-invoice-{date}        →  stripe-invoice-2025-06-20.pdf
github-{original}-{year}     →  github-release-v2-1-0-2025.zip
{domain}/{date}-{original}   →  notion-com/2025-06-20-export.csv

Frequently Asked Questions

Why isn't Filer renaming my files?

The most common reason is a missing permission. Go to chrome://extensions → Filer App → Details and confirm that "Allow in Incognito" is set if you're in incognito mode, and that "Site access" is set to On all sites. Also make sure at least one rule is active.

Will Filer work with files I drag into my browser?

Filer only processes files triggered via the browser's native download mechanism. Files dragged into apps directly or saved from other apps are not intercepted.

Does Filer move existing files in my Downloads folder?

No. Filer only acts at the moment of download. It does not scan, move, or modify existing files.

Can I use Filer on multiple devices?

Yes. Install Filer on each device and enter your licence key under Options → Account on each one. Rules are not automatically synced across devices — you'll need to set them up on each.

What happens if I exceed the 3-rule free limit?

You cannot add a 4th rule without upgrading. Your existing 3 rules continue to work. Upgrade to Pro for unlimited rules.

I lost my licence key. What do I do?

Contact us at the email below with your purchase email address. We'll look up your key and resend it.

Is my data backed up?

Your settings and rules are stored in Chrome's sync storage if Chrome sync is enabled, which means they may be available across devices. Activity history is local only and is not synced or backed up externally.

Does Filer work in Incognito mode?

By default, Chrome extensions are disabled in Incognito. To enable Filer in Incognito: chrome://extensions → Filer App → Details → toggle Allow in Incognito.
